# Frontend Web Applications (`frontend/`)

## Architecture Overview
The user interface is built with **React**, **Vite**, and **TypeScript**, styled with clean Vanilla CSS design tokens.

## User Portals
1. **Citizen Living Record Portal:**
   - Passwordless mobile OTP login.
   - Household profile verification and update forms.
   - Multimodal Malayalam Voice Grievance recording using OpenAI Whisper STT in browser.
2. **Panchayat Administrative Planning Dashboard:**
   - Interactive ward choropleth maps powered by Leaflet & PostGIS GeoJSON.
   - Candidate Issue verification queue for elected Ward Members and Secretary.
   - One-click Annual Plan Project Brief generator (PDF / LaTeX export).
